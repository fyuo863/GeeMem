# 召回证据拼接试验

## 行为

在长提示词/短提示词多跳流程的最终融合之后、Top-K 截取之前，复用最后一轮审核的支持证据。审核结束状态必须为 sufficient，支持来源必须为 2–4 条，每条引文再次通过原文子串校验。程序将排名最高的一条标为“核心原文”，其余标为“关联原文”；这些标签只是展示位置，不表示模型已确定终点/中间节点或新旧有效性。

每段包含原文来源 ID、该段来源时间和完整原文，不使用模型改写的结论或 needed_for 描述。整个组合最多 6000 字符（含标头），超限则完全回退逐条返回，不截断、也不构造半条证据链。一次请求最多生成一个组合；占一个 Top-K 位置，成员原文在当前结果中去重，其余候选依原排序补位，结果数量不超过 top_k。

开关：根 `.env` 的 `RAG_EVIDENCE_BUNDLE_MODE=on`，示例配置默认 off。不开启时保持原流程。普通 atomic 流程和 focused 实验路径不进行拼接。启用时原问题初次检索的候选数至少为 `min(16, RAG_MULTIHOP_EVIDENCE)`，避免小 top_k 在审核之前丢掉关联来源；不会新增检索调用，但可能改变既有审核和后续查询次数。组合本身新增模型调用为零。

## 接口与追溯

外部仍返回 `data[].id/content/score`。组合的 id 使用 `bundle_` 前缀，由版本、user_id 和包含来源 ID/时间的完整组合文本生成 SHA-256。不同成员、顺序、内容或用户生成不同标识；不冒用核心原文 ID。组合不返回一个易误导的统一 created_at，每段时间保留在 content 中。score 沿用核心项的排序分数，不表示事实可信度。

同一个数据库中的 `rag_evidence_bundles(user_id,bundle_id,source_ids)` 保存组合到来源 ID 的映射。查回流程：

```text
user_id + bundle_id
  → rag_evidence_bundles.source_ids
  → rag_memories.id + 同一 user_id
  → 原文、request_id、session_id、message_index、timestamp
  → rag_sources 中的 source_id 与 char_start/char_end
```

映射只保存 ID，不重复保存原文；仍属于该用户记忆的数据生命周期，删除官方评测数据时也要清理此表。当前没有新增公开追溯接口。组合元数据在后端持久化后移除，不泄漏 `_bundles` 到 API。

官网明确读取 content、保留候选，并忽略未声明 metadata；因此来源标头直接写入 content，而不是依赖自定义字段。官网未明确认可组合记忆的粒度，此版仅本机实验，不自动部署赛事服务。

## 测试与限制

自动化覆盖：原文完整性、稳定 ID、用户作用域、成员去重补位、长度限制、不充分审核回退、伪造引文拒绝、Top1 中保留关系链、映射持久化与内部字段移除。

真实测试脚本 `scripts/test_evidence_bundle_real.py`，使用既有人工场景隔离库的 SQLite backup 副本，调用本机 FastAPI `/search` 和根 .env 配置的真实模型。比较 4 道题、8 次查询的 Top1 来源覆盖；该指标表示组合内包含多少条金标原文，**不是与单条结果公平等预算的 Recall@1**。完整测试集、官方分数及长链泛化尚未验证。

首轮：关系链从 1/3→3/3、规则例外从 1/2→2/2；当前值维持 1/1，冲突题仍为 1/2。随后修正初次 Top1 候选过窄问题，再次运行最终代码。

最终代码复测（`data/evidence-bundle/20261010T053119Z/report.json`）：

| 场景 | 关闭时 Top1 金标来源覆盖 | 开启后 | 返回字符数（前→后） |
|---|---:|---:|---:|
| 当前居住地 | 1/1 | 1/1，不拼接 | 63→63 |
| 地址冲突双方 | 1/2 | 2/2 | 107→411 |
| 出租车规则及例外 | 1/2 | 2/2 | 58→405 |
| 兄弟→老师→乐器 | 1/3 | 3/3 | 37→464 |

三条组合映射全部可在同用户原文库中查回。最终核心实现全套回归 344 项通过；随后补充的候选扩展失败回退测试也通过（证据包专项共 8 项）。本机根 `.env` 已开启该功能，新建后端或重启本机服务后生效；服务器未修改。

仍有的边界：只能拼接已找到且最后审核选中的证据；没召回或审核漏选的中间来源不会凭空补齐；引文校验不证明语义关联正确；不能把拼接新旧原文等同于完成事实替代。已有 primary/context 选择器是独立实验，建议维持关闭，避免对组合再次作不可靠的状态排序。此实现不额外猜测邻近消息关系，不实现新的关联图。
