# 2026-10-09 检索修复与 Qwen 重排 API 对照

## 决策与修复

本机选择 `qwen3.7-text-rerank`，使用百炼原生 API。复用根目录 `.env` 中已有百炼凭据，未记录密钥，未修改服务器或官方正在运行的版本。

1. 恢复目标消息的相邻上下文（前后各一条/块），同用户、同会话；保存输入显式提供的人物标签，不猜测身份。
2. 将内部检索文本传递到多跳审查和最终重排，避免最后一步退回裸原文。审查中原文与上下文共用原有字符上限，不增加 LLM 调用预算；要求引用仍来自目标原文。
3. 解析 `31 July, 2023`、`July 31st, 2023`、月份/年份等英文日期；缺年份、不合法日期、复杂多条件仍保守回退。旧时间索引读时重新执行规则解析，不调用 LLM、不重新向量化。
4. API 支持原生 DashScope 请求，验证返回索引完整、唯一、有限；最多 500 文档整池一次请求。分数只在同请求内可比较，不套用 MiniLM 的跨请求目标分数校正。超时 60 秒、网络及特定状态码最多重试一次，失败不伪造结果。

已丢弃姓名的旧输入无法自动恢复；名字前缀必须由调用者提供。新版公共数据测试适配器可保留数据集姓名，但下面的模型对照没有使用这项额外信息。

## 实验方法

- LoCoMo-Refined 公共纯文本题，10 个会话样本各 8 题，共 80 题；全部有证据标注。
- 排除之前用于定位问题的 40 题。按固定哈希抽取，预分为 40 题初筛、40 题验证；没有调整问题、模型指令或训练权重。
- 共用已有 `text-embedding-v4` 向量和每题同一候选池（预算 400）。输入仍为旧 role-only 原文，不补充说话者姓名。
- 对照只测重排，不启用规划、分区或时间增强；每题每个变体都真实运行。金标仅用于计算指标，不进入候选构造或模型输入。
- 旧 MiniLM：上下文关闭、目标校正关闭。修复 MiniLM：上下文 1、目标校正及 context_support 开启。Qwen：上下文 1，使用 API 原生分数。
- 这是适合各模型的配置对比，不是只替换一个模型权重的严格消融；三组初始候选 ID 相同。

## 80 题结果

| 指标 | 旧 MiniLM | 修复 MiniLM | Qwen API |
|---|---:|---:|---:|
| Recall@5 | 46.25% | 74.38% | 88.54% |
| Recall@10 | 55.00% | 81.88% | 93.54% |
| Hit@10 | 57.50% | 83.75% | 95.00% |
| Micro Recall@10 | 50.00% | 75.53% | 87.23% |
| 全证据命中@10 | 52.50% | 80.00% | 92.50% |
| Recall@100 | 87.92% | 95.00% | 99.27% |
| 平均重排耗时 | 0.176s | 0.518s | 0.919s |
| P95 重排耗时 | 0.283s | 0.578s | 1.130s |

耗时只包含重排，不是完整 `/search`；MiniLM 使用本机 GPU，Qwen 包含网络。
Recall 是逐题证据召回率的宏平均；Micro Recall 按证据数加权；Hit 为至少命中一条；全证据命中为全部标注证据入榜。

单独的 40 题验证集，三组 Recall@10 分别为 **47.50%、80.00%、98.75%**，Hit@10 为 **50.00%、82.50%、100.00%**。初筛的 Qwen Recall@10 为 88.33%，两组存在明显样本差异，不将较高的验证子集成绩外推。

修复 MiniLM 相对旧配置：24 题改善、1 题退化、55 题持平。Qwen 相对修复 MiniLM：11 题改善、1 题退化、68 题持平。
唯一后者退化题：`What is something that Andrew really misses while working in the city?`，Recall@10 从 0.5 降至 0。上下文帮助理解，但也可能将相关邻居置于真正目标证据之前。

结论：修复输入与上下文比单纯换模型更基础；修复之后换 Qwen 仍提高 11.67 个百分点的 Recall@10，平均增加约 0.40 秒重排延迟，足以支持本机切换。Micro Recall@10 仍未达到 90%，不能说所有召回目标已经完成。

## 验证与复现

- 自动化：`python -m pytest tests -q -p no:cacheprovider`，320 项通过。
- 对照：`python scripts/compare_qwen_rerank.py`；逐题排名及指标位于 `data/final-text-validation/qwen-repairs80-20261009/`。
- 真实接口：`python scripts/smoke_qwen_repairs.py`，隔离库、3 个会话共 58 条真实消息，6 道原始纯文本题，真实 v4/Qwen/gpt-4o-mini；标准 Add/Search 字段，通过内容前缀保留数据集姓名，无提问时钟注入。
- 6 题均全部召回标注证据，无 HTTP 错误，返回内容核对为原文。该用例只在三个会话中检索，属于功能联调，不能与完整会话库的 80 题质量直接比较。
- 接口报告位于 `data/final-text-validation/qwen-smoke-20261009/report.json`，包括规划策略、回退、查询次数与端到端耗时。

本轮没有重跑 861 题全量、没有重新嵌入生产库、没有推送或部署。正式更换线上模型前应完成全量回归，并遵守官方 Full 评测期间版本冻结要求。API 用量成本没有完整计量，本次仅比较质量和延迟。
