# 时间索引第一版：实现与真实召回测试（2026-10-09）

本轮实现的是原文时间标注、确定性日期归一化、来源索引和检索增强。不是完整事件推理器，不在 /search 生成答案，也不把标注直接视为事件发生时间。

## 实现

- `/add` 先保存原文与向量，再以程序生成的 source_id 建立 rag_time_mentions 侧索引；重复请求不会重复标注。
- TimeAnnotator 只返回原文时间片段、标签、置信度；程序校验来源并赋字符偏移。
- TemporalNormalizer 支持完整年月日、带年份英文日期、昨天/今天/明天、数字天/周前、上/下月与上/下年。月份用区间，缺年份日期、模糊时间与不支持表达标记 unknown。
- 消息时间仅锚定明确的相对表达，不能替代事件时间。月/年归一化由程序完成。
- 检索只在时间问题上补充归一化时间及来源元数据，仍使用同一个词法/向量召回和重排器。返回 content 始终为原文。
- latest/earliest 仅对含单一明确日期、相关分数接近的候选作最多两位的调整；顺序/比较题保留多个端点，不按消息时间硬排序。
- 原文索引按 user_id 隔离，日期片段必须落在返回块的字符范围内。

## 开关与模型预算

只读取根目录 `.env`。`RAG_TEMPORAL_MODE=on` 开启写入/读取侧索引；`RAG_TIME_ANNOTATION_MODE=on` 开启可选 LLM 片段选择。两项默认 off，未修改本机或远端生产配置。

LLM 每次 Add 最多处理两个预筛命中的消息，每条最多 6000 字符；每调用最多两次传输尝试，每次 HTTP timeout 为 60 秒。预算外或失败保留规则片段，并在 status 中区分 annotated、budget_skipped、annotation_failed_rules_retained、rules。当前不会自动重试已经落库的失败/跳过项；后续完整重标注需要显式回填机制。

## 测试条件

- LongMemEval-S 中缓存可用的 20 道非拒答 temporal-reasoning 题，按固定哈希顺序取前 10 道。选择不依赖命中结果，不能代表随机全量估计。
- 10 个完整会话集合，共 6710 个原文块、27 条金标消息；逐块核对与原数据的 ID/内容一致。
- 使用既有、embedding/chunk identity 完全一致的 text-embedding-v4 向量缓存；相同查询向量供两组复用。
- 两组均使用英文 MiniLM 重排、400 候选、top_k=10、窗口关闭、多跳和分区规划关闭；不是线上 BGE + 完整规划流程成绩。
- 真实 /search 经 TestClient 调用；时间侧索引从原始会话回填。单独的接口测试验证 /add 接入，但这轮长会话没有重新执行全量 /add 或向量化。
- 真实 gpt-4o-mini 标注调用 4 次，3 次成功、1 次失败后规则回退；5054 条源消息完成规则索引。主要召回对照为规则索引增强，不能声称已测试全量 LLM 标注。
- 底层索引记录含 237 条可归一化片段、155 条 unknown（含侧索引版本记录）；这不是人工金标标注准确率。
- 关闭组耗时包含远端查询向量请求，开启组复用向量；均值不适合作为加速结论。

## 结论与缺口

两题 Recall@10 提升、八题不变、零题退化，三题的返回排名发生变化。总体多召回 2 条金标消息（17/27 → 19/27）。效果来自时间索引文本和来源元数据参与检索/重排的整体改动，本实验未单独隔离哪一个字段产生收益。

- 一月体育赛事排序：2/3 → 3/3，证据完整性改善。
- 连续两天慈善活动：3/5 → 4/5，仍遗漏 Books for Kids 活动原文，时间标注不能自动补全所有事件。
- 三次旅行排序仍为 1/3：漏掉提及 Yosemite 露营和 Big Sur/Monterey 自驾的片段；需要事件覆盖、多证据召回，而不是把已召回片段重新按日期排列。
- 慈善活动计数仍为 3/6：漏掉高尔夫、骑行和野生动物活动。其原文同时询问建议，且有缺年份日期，不能靠日期排序恢复完整列表。
- 情人节航班仍为 1/3：航空公司与当天经历分布在不同片段，节日和日期/事件关联仍未建模。

只可结论为本轮 10 题有小范围收益，尚不支持全面开启或泛化结论。下一阶段应优先补全事件集合、跨片段事件/时间关联与查询参考时间；日期计算仍留给程序，最终答案留给上层模型。
